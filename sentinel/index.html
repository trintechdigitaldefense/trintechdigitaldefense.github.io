WHAT SENTINEL DOES

Sentinel combines passive network monitoring with active deception to provide comprehensive security visibility for businesses that do not have a dedicated security team.

📡
NETWORK DISCOVERY
Scans your network subnets to discover every connected device. Fingerprints each device to identify operating system, vendor, and hardware type. Maintains a persistent database of first and last seen timestamps for every device.
🪤
ACTIVE DECEPTION
Deploys decoy files containing fake credentials, API keys, and database configurations in strategic locations. If an unauthorized user accesses a decoy, the system logs exactly what they did and when. Fake SSH banners and service registries deter and track intruders.
🐕
PERSISTENCE HUNTING
Continuously monitors for new devices, new open ports, and authentication failures. Tracks behavioral patterns over time to identify anomalous activity that static tools would miss. Alerts on anything that should not be on your network.
🚨
ALERT SYSTEM
Generates structured alerts with severity classification. Alerts can be logged to file, sent via email via Gmail SMTP, or delivered through custom integrations. Console alerts with color-coded severity indicators for real-time monitoring.
📊
REPORTING
Generates comprehensive reports showing all discovered devices, port information, deception deployment status, and recent alerts. Reports are designed for business owners, not just security professionals.
🔒
SYSTEM INTEGRITY
Monitors file integrity on critical system files, tracks changes to SSH configurations, detects new SUID binaries, and validates user account changes. Ensures that no unauthorized modifications occur on your systems.
