DETAILED FINDINGS

Severity Finding Details Remediation Affected
CRITICAL Unpatched Apache Log4j (CVE-2021-44228) Apache Log4j 2.x found on web server with RCE vulnerability. Remote attackers can execute arbitrary code. Update Log4j to version 2.17.1 or later immediately web-server-01.trintech.tt:443
HIGH SSL/TLS Weak Cipher Suites Enabled Server supports RC4 and 3DES cipher suites which are known weak encryption algorithms. Disable weak cipher suites, enable only TLS 1.2+ with AES-GCM ciphers web-server-01.trintech.tt:443
MEDIUM Missing X-Frame-Options Header Web application does not set X-Frame-Options header, allowing clickjacking attacks. Add 'X-Frame-Options: DENY' header to all pages web-app.trintech.tt
LOW Default SSH Configuration (Port 22) SSH service running on default port 22, increasing brute-force attack surface. Change SSH to non-standard port, disable password authentication, use key-based auth only 192.168.1.10
