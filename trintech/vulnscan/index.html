📊 Baseline Comparison

Track Security Over Time

Save scan results as baselines and compare against new scans to see:

🔻 Ports Closed

Ports that were open in the baseline but closed in the current scan — improved security posture.

🔺 Ports Opened

Newly opened ports flagged for review — potential unauthorized changes or misconfigurations.

📈 Security Score Delta

Point change in overall security score between baseline and current scan.

Example score progression: baseline 42 → after hardening 78 (+36)

📖 Quick Reference Cheatsheet

Start the Server
# Launch the Flask API server
cd /opt/baal-agent/workspace/TrinTech/VulnScan
python3 vulnscan_server.py --port 5056
Run a Network Scan
# Scan a subnet for common ports
curl -X POST http://localhost:5056/api/scan \
  -H "Content-Type: application/json" \
  -d '{"subnet": "192.168.1.0/24", "ports": "22,80,443,3306,8080"}'

# Check scan progress
curl http://localhost:5056/api/scan/status
Baseline Management
# Save a baseline after a scan completes
curl -X POST http://localhost:5056/api/baseline \
  -H "Content-Type: application/json" \
  -d '{"label": "initial-audit", "scan_result": {...}}'

# List all baselines
curl http://localhost:5056/api/baseline

# Compare current scan against a baseline
curl -X POST http://localhost:5056/api/baseline/compare \
  -H "Content-Type: application/json" \
  -d '{"baseline_id": "baseline-xxx", "subnet": "192.168.1.0/24"}'
Report Generation
# Generate HTML vulnerability report
curl -X POST http://localhost:5056/api/report \
  -H "Content-Type: application/json" \
  -d '{"scan_result": {...}}'

# Push findings to Log Correlator
curl -X POST http://localhost:5056/api/logcorr/ingest \
  -H "Content-Type: application/json" \
  -d '{"target": "http://localhost:5053", "findings": [...]}'
